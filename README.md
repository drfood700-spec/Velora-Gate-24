# 🛒 متجر الحسابات - بوت تلغرام

بوت احترافي لبيع حسابات Apple ID و Gmail و iCloud مع نظام إحالة وشحن رصيد.

## المميزات
- ✅ عرض المنتجات مع المخزون
- ✅ نظام إحالة (10% أرباح)
- ✅ شحن رصيد عبر طرق متعددة
- ✅ لوحة تحكم إدمن كاملة
- ✅ عرض سعر الصرف
- ✅ عرض الرصيد بالدولار والليرة

## النشر على Railway
1. ارفع الملفات على GitHub
2. أنشئ مشروعاً على Railway
3. أضف المتغير BOT_TOKEN
4. شغّل الأمر: python main.py
